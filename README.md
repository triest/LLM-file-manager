# Локальный файловый менеджер

Небольшое Windows-приложение с поиском по содержимому файлов, просмотром извлечённого текста, открытием в установленном офисном приложении и локальным ИИ через Ollama. Приложение работает как обычное окно Tkinter, без OpenServer, веб-сервера и облачных API.

## Первый запуск

1. Выполните `CreateShortcut.ps1` (если Windows блокирует сценарий: откройте PowerShell в этой папке и выполните `powershell -ExecutionPolicy Bypass -File .\CreateShortcut.ps1`). Это создаст ярлык `Local File Manager` на рабочем столе.
2. Запустите приложение двойным щелчком по ярлыку.
3. Нажмите **Добавить папку**, укажите нужную папку на N: и нажмите **Сканировать**.

Индекс хранится отдельно в `%APPDATA%\LocalFileManager\files.sqlite3`; сами файлы не загружаются и не копируются. Выбранные папки сохраняются для следующего запуска. Сканер пропускает системные папки и файлы больше 100 МБ.

## Локальные модели на этом компьютере

В локальном хранилище Ollama обнаружены `qwen2.5:3b`, `qwen2.5:7b`, `deepseek-r1:14b`, `qwen2.5vl:7b` и `qwen3-vl:4b`.

- **qwen2.5:7b** — основной выбор для вопросов по документам и плана сортировки; качество/скорость сбалансированы.
- **qwen2.5:3b** — для более быстрой работы и меньшего потребления памяти.
- **deepseek-r1:14b** — более сложные рассуждения, но ответы дольше.
- **qwen2.5vl:7b** и **qwen3-vl:4b** — задачи с изображениями; текущий прототип индексирует текст документов, а не анализирует изображения.

При запуске приложение проверяет Ollama и, если возможно, тихо запускает локальную службу. В настройке Ollama используется найденное хранилище моделей `J:\OllamaModels`. Планы сортировки только предлагают действия; перемещение и переименование выполняются отдельными кнопками после выбора файла.

## Форматы

Текстовый поиск и предпросмотр поддерживают DOCX, XLSX, PPTX, ODT/ODS/ODP, TXT, Markdown, CSV, HTML и код. PDF имена индексируются всегда; извлечение содержимого PDF доступно, если в Python установлен `pypdf` (`python -m pip install pypdf`). Таблицы и презентации индексируются как текст, макет и формулы не анализируются.

Для запуска нужен установленный Python 3.10+ с Tkinter. Внешних Python-пакетов для базового режима не требуется.
